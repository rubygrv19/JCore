# Dashboard Minimal

Starter dashboard satu halaman dengan Nuxt 4, Nuxt UI, Nuxt Fonts, dan Nuxt Icon. Angka dan transaksi yang ditampilkan adalah data contoh.

## Menjalankan

```bash
pnpm install
pnpm dev
```

Buka alamat lokal yang ditampilkan Nuxt.

## Perintah

- `pnpm dev` — jalankan server pengembangan
- `pnpm build` — buat build produksi
- `pnpm preview` — pratinjau build produksi
- `pnpm typecheck` — periksa tipe TypeScript
- `pnpm lint` — jalankan ESLint
